# VisionYoon
**Machine Vision & PLC Control Projects**  
이 저장소는 머신 비전 및 제어 관련 프로젝트를 관리합니다.  

---

## 📂 프로젝트 구성

### 1. **DOTNumberReading**
   - 숫자를 인식하는 머신 비전 프로젝트
   - OCR(광학 문자 인식) 기술 사용
   - C# 기반 소프트웨어

### 2. **MFC_CIRCLE_DRAWER**
   - MFC 기반 원형 그리기 프로그램
   - 사용자 입력에 따라 원을 그리는 기능 포함
   - C++ 기반 소프트웨어

### 3. **PLC_program**
   - PLC(Programmable Logic Controller) 제어 코드
   - 공정 자동화 및 장비 제어 구현
   - C# 관련 소프트웨어와 관련 프로토콜 사용
